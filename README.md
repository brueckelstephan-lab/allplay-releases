# Allplay – Downloads

Hier liegen die fertigen Android-Versionen von Allplay (APK). Die App prüft diese Seite selbst
und bietet neue Versionen unter „Hilfe und Einstellungen → App-Version“ an.

- **Neueste Version:** unter [Releases](../../releases/latest) die Datei `Allplay-<version>.apk`.
- **Testversion:** Release `kandidat` (z. B. mit neuem YouTube-Teil), wird erst nach Freigabe zur normalen Version.
- Jede Version ist mit demselben Schlüssel signiert. SHA-256 des Zertifikats:
  `ac734fe4990cf7edfb755c7b332222c628fc0b3907c97ed801dd510e3bb491ab`

Der YouTube-Teil stammt aus [PipePipeExtractor](https://github.com/InfinityLoop1308/PipePipeExtractor) (GPL-3.0).
